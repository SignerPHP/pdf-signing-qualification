# Synthetic fixtures

Small, original files created for this repository's tests. Upstream and user-reported PDFs never go here; see [CONTRIBUTING.md](../../../CONTRIBUTING.md).

Every file in this directory must be listed below, by its path relative to this directory, before it is committed.

| File | Owner | How it was produced | Purpose |
| ---- | ----- | ------------------- | ------- |
| `CertifiedPdf.php` | SignerPHP | Written for this repository; writes at test time a one-page PDF 1.7 certified by a signature dictionary registered as `/Perms` `/DocMDP` with a DocMDP transform of a chosen `/P`, an uncertified one, and incremental updates that add an approval signature, a certification signature (indirect or direct in its field) or a document timestamp; the `/Contents` are zeros, because the analyzer it serves reads only the structure | Inputs and outputs of the [`qpdf-certification-permissions`](../../../schemas/README.md) analyzer tests: `/P 1`, `/P 2` and `/P 3` certifications and an uncertified input |
| `HybridXrefPdf.php` | SignerPHP | Written for this repository; writes `hybrid-xref.pdf` at test time, a PDF 1.5 whose catalog, page tree and page are in an object stream listed only by the cross-reference stream that the trailer names with `/XRefStm` | Input of the [`hybrid-xref`](../../../docs/regressions.md#hybrid-xref) regression case |
| `MinimalPdf.php` | SignerPHP | Written for this repository; writes `minimal.pdf` at run time, a one-page PDF 1.4 with a classic cross-reference table and no content, through `SyntheticPdf.php` | Fixed-cost reference of the [performance study](../../../docs/performance-protocol.md) |
| `PadesCatalogEntriesPdf.php` | SignerPHP | Written for this repository; writes at test time, through `SyntheticPdf.php`, a one-page PDF 1.4 whose catalog holds a chosen `/DocMDP`, `/DocTimeStamp` or `/Perms /DocTimeStamp` entry pointing to an object that points to another, and an incremental update of it that keeps or adds that entry or changes either object | Inputs and outputs of the `qpdf-pades-structure` tests that tell an entry the input already holds from one the implementation added |
| `SignatureFieldNamePdf.php` | SignerPHP | Written for this repository; writes at test time, through `tests/Validation/SyntheticSignedPdf.php`, `non-ascii-field-name.pdf`, signed in a field whose name is UTF-8 text with its byte order mark, which qpdf decodes and PDFBox reads as PDFDocEncoding, and `undecodable-field-name.pdf`, signed in a field whose name holds bytes PDFDocEncoding leaves undefined, which qpdf keeps as bytes and PDFBox replaces | Inputs whose prior signature `eu-dss` and `demoiselle-signer` must tell apart from the added one without comparing field names |
| `SyntheticPdf.php` | SignerPHP | Written for this repository; writes one-page PDFs with a classic cross-reference table at test time, with chosen objects, header version and incremental updates | Inputs of the strata classifier tests, and of `MinimalPdf.php` |
